feat: implement core backend architecture and library features

This commit establishes the foundational Spring Boot backend for the offline
library application, completely addressing the core requirements for user 
management, security, traceability, and book interactions.

Architecture & Foundation:
- Configured programmatic session-based Spring Security (Login/Logout/Me)
- Implemented global exception handling with standard ApiResponse wrappers
- Created DataSeeder to auto-generate the root Admin account and RBAC structure

User & Access Management:
- Created granular Permission and Role entities mapped to User accounts
- Implemented registration endpoint (users default to PENDING status)
- Built UserManagement API for Admins to approve/ban users individually or in bulk

Library Core:
- Created entities for Books, Categories, Tags, Authors, and Series
- Built Book upload system with local filesystem storage for offline environments
- Added inline secure PDF streaming endpoint to prevent raw downloads
- Configured Hibernate Search (Lucene) for full-text indexing on titles and descriptions

Interactive Features & Traceability:
- Built threaded comment system (with draft support)
- Implemented Reading Progress API to persist user page bookmarks
- Implemented comprehensive AuditLog listeners tracking critical system events
